# TiAuto Finance Intelligence

This build is a direct client-tailored replica of the original Telkom Enterprise Finance Intelligence application.

It preserves the same application architecture, cinematic landing experience, Executive Command Centre, full-screen Ask Finance Intelligence workspace, Agent Mission Control, Finance Intelligence Domains, Working Capital, Financial Close, Reconciliation Intelligence, Payment & Automation Intelligence, Cashbooks & Banking Intelligence, Executive Reporting, Knowledge Layer, Operating Model and 90-Day Activation Plan.

The content is tailored to TiAuto's May 2026 MBR, including:

- DSO of 33 days
- R63m collections against a R68m target
- R8.5m cash and card drops not reflected as banked
- Continental R345k Easter Campaign balance
- ABSA Fleet R114k allocation/remittance exception
- 264 payments captured
- 100% reconciliation coverage
- May month-end completed on time
- Payment automation and Python conversion dependencies

## Run

Double-click `RUN_TIAUTO_FINANCE_INTELLIGENCE.bat`, or:

```bash
npm install
npm run dev
```

## Demo status

This is a demonstrator grounded in the May 2026 MBR. It is not connected to live Sage, BIO, banking or operational systems.
